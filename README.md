# DDBX

DDBX is a public Codex plugin for researching disclosed director dealings and insider share transactions. It prioritizes issuer, exchange, and regulatory filings, and distinguishes discretionary transactions from planned sales, option exercises, tax withholding, gifts, and indirect ownership where disclosed.

## Install

```sh
codex plugin marketplace add jonwillington/ddbx-chatgpt-plugin
codex plugin add ddbx@ddbx
```

Start a new Codex session after installation, then ask, for example: `Find recent director buys for Nvidia.`

## Scope

DDBX is a research aid, not investment advice.
